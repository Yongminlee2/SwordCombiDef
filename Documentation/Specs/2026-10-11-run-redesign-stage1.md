# 한 판 구조 개편 1단계 — 각인 빌드 + 손으로 끼는 전투 + 디자인 기준

작성 2026-10-11 · 대상 버전 0.13.0 (17)

## 왜 바꾸나

사용자 피드백(0.12.0 실기기 플레이 후): 디자인은 괜찮은데 게임 방식이 재미없다.
구체적으로 네 가지 모두 해당한다.

1. 할 게 단순하다 — 소환 누르고 같은 것 합치기만 반복, 고민해서 고르는 순간이 없다.
2. 내가 전투에 안 낀다 — 검이 알아서 싸우고 나는 구경한다.
3. 성장이 안 느껴진다 — 세지는 게 체감되지 않는다.
4. 목표가 없다 — 다음 판을 할 이유가 약하다.

방향(사용자 승인): 로그라이크 빌드형(발라트로·슬레이 더 스파이어 느낌)을 중심으로,
원소 시너지와 직접 개입을 섞는다. 세 단계로 나누고 이 문서는 1단계만 다룬다.

| 단계 | 내용 | 해결하는 불만 |
|---|---|---|
| **1 (이 문서)** | 매 웨이브 각인 3택1, 궁극기 직접 발동, 집중 공격 탭, 전투력 표시, 디자인 기준·폰트 | 1, 2, 3 |
| 2 | 원소 별자리 시너지(인접 배치) | 1 |
| 3 | 각인 수집·해금, 판 사이 목표 | 4 |

## 지키는 것

- 검 60종 그림, ContentCatalog의 검·레시피·적 데이터, 도감, 조합서는 그대로.
- 세로 화면, 한 손, 하단 버튼 3개(소환/조합서/도감), 적 60마리 패배, 전체이용가.
- 판매(소환 버튼으로 드래그), 눌러서 제작, 공명 소환 등 0.12.0 기능 유지.
- Core는 Unity를 모른다(기존 아키텍처 규칙). 새 규칙은 전부 Core에 두고 테스트한다.

## 1. 각인(Engraving) 카드

### 1-1. 언제 고르나

- 웨이브의 적이 모두 나온 순간(= 휴식 시작, `CombinationDefenseState.Intermission` 진입)마다
  카드 3장이 뜨고 1장을 고른다. 고르는 동안 시간 정지(기존 룬 선택과 동일한 일시정지).
- 보스 웨이브(5의 배수)가 끝나면 희귀 이상 1장이 반드시 포함된다.
- 기존 "보스 처치 시 룬 선택"은 이 흐름으로 흡수한다(보스를 늦게 잡아 보상이 밀리던 문제도 사라짐).
- 무한 모드도 매 웨이브 동일.
- 같은 각인은 한 판에 한 번만 나온다. 뽑을 게 3장 미만이면 있는 만큼만 보여준다(0장이면 건너뜀).

### 1-2. 등급과 확률

| 등급 | 테두리 색 | 일반 웨이브 | 보스 웨이브 |
|---|---|---|---|
| 일반 | 회청 | 70% | 0% (보장 칸 제외) |
| 희귀 | 파랑 | 25% | 보장 1장 + 나머지 70/25/5 |
| 전설 | 금 | 5% | 위와 같음 |

### 1-3. 꼬리표와 카드 목록

같은 꼬리표를 모을수록 세지도록 짠다. 수치는 시뮬레이터로 최종 조정한다(아래는 시작값).

**기존 룬 24개 → 일반 등급 각인으로 편입** (`RunContentCatalog.Runes` 그대로, 꼬리표 `기본`).

### 1-4. 화면

- 카드 3장이 세로로 놓인 선택 화면(기존 룬 선택 레이아웃 재사용).
  - 카드 = 등급색 테두리 + 꼬리표 글자("합성", "판매" 등 — 이모지는 폰트에 없어 쓰지 않음)
    + 이름(함렛) + 효과 한 줄(프리텐다드).
  - 이미 가진 같은 꼬리표 개수를 카드 구석에 "합성 ×2"처럼 표시해 빌드 방향이 보이게 한다.
- 상단 HUD 아래 작은 각인 줄: 고른 각인을 꼬리표 색 점으로 쌓아 보여주고, 누르면 목록(일시정지).

## 2. 손으로 끼는 전투

### 2-1. 궁극기 직접 발동

- 자동 발동 제거. `CombinationDefenseSession.TryUseUltimate()` 공개 메서드로 바꾼다.
- 게이지가 100%가 되면 보드 아래 가운데(하단 버튼 줄 위, 현재 "웨이브 N 시작" 글자 자리)에
  둥근 버튼이 성좌 청록으로 빛난다. 누르면 발동, 안 누르면 보관.
- 0~99%일 때도 같은 자리에 흐린 원형 게이지로 보여 준다(지금 왼쪽 위 "검우 74%" 글자는 제거).
- 시뮬레이터 봇은 기존 자동 조건(적 20마리 이상 또는 보스 존재)일 때 누른다.

### 2-2. 집중 공격 탭

- 외곽을 도는 적을 탭하면 조준 표시, 5초 동안 사거리 안의 모든 검이 그 적을 첫 대상으로 고른다
  (사거리 밖이면 평소대로). 다른 적을 탭하면 대상이 바뀐다.
- 적 그림이 작아서 손가락에 맞도록 터치 영역은 그림보다 1.6배 크게 잡는다.
- Core: `SetFocus(runtimeId, seconds)`, `FindTargets`에서 집중 대상을 맨 앞에 둔다.
- 검 드래그(판매·합성)와 겹치지 않는다: 적은 보드 바깥 외곽에만 있다.

## 3. 성장이 보이게

- 상단에 **전투력** 숫자: 보드의 모든 검의 초당 피해(각인·등급 반영) 합.
  Core `CombatMath.BoardPower(...)`로 계산, 값이 바뀌면 0.4초 동안 숫자가 굴러 올라가며 커졌다 작아진다.
- 카드를 고르면 전투력 변화(+18%)를 카드 선택 화면이 닫히는 순간 크게 한 번 보여 준다.

## 4. 디자인 기준

### 4-1. 색 (7색 고정, `GameTheme` 교체)

| 토큰 | 값 | 쓰임 |
|---|---|---|
| Night | `#0E1430` | 배경, 글자 받침판(70~85% 불투명) |
| Nebula | `#2A2358` | 패널 |
| Starlight | `#F3F1FF` | 기본 글자 |
| Muted | `#B9C2DE` | 보조 글자(기존 `#A9B2CA`보다 밝게) |
| EmberGold | `#FFC24A` | 골드·비용·전투력 등 **숫자에만** |
| ConstellationCyan | `#6FE3F0` | 지금 누를 수 있는 것(눌러서 제작, 궁극기 준비, 집중 표식) |
| WarningCoral | `#FF6B6B` | 적 압박(게이지·경고) |

등급색(회청/파랑/보라/금/무지개)은 기존 그대로 검·카드 테두리에만 쓴다.

### 4-2. 글자 규칙

- 그림 장식 위에 글자를 바로 올리지 않는다: Night 받침판 또는 2px 어두운 외곽선.
- 금색 글자는 숫자 전용. 제목은 Starlight, 장식 테두리 위 제목은 받침판 위에.
- 크기 3단계(기준 해상도 1080 폭): 큰 숫자 32+, 본문 24, 작은 글씨 20. 18 미만 금지.
- 비활성은 회색이 아니라 50% 불투명.

### 4-3. 폰트 (OFL, 사용자 다운로드 승인 완료)

| 역할 | 폰트 | 파일 |
|---|---|---|
| 제목·검 이름·각인 이름·결과 제목 | 함렛(Hahmlet) Bold | `Assets/Resources/Fonts/Hahmlet-Bold.ttf` (2.0MB) |
| 나머지 전부 | 프리텐다드(Pretendard) Bold | `Assets/Resources/Fonts/Pretendard-Bold.ttf` (2.7MB) |

- `UiFactory.DefaultFont` → 프리텐다드, `UiFactory.TitleFont` 추가 → 함렛.
- NotoSansKR은 폴백으로 남기지 않고 제거(용량). 라이선스 전문은
  `Documentation/ThirdPartyLicenses/`에 추가, 기존 Noto 라이선스는 제거.
- 이 게임의 "한 방": 새 검 발견 연출과 각인 카드 이름을 함렛으로 크게. 나머지는 조용하게.

## 5. 난이도

- 각인이 매 웨이브 쌓이므로 적 체력 곡선(`LateWaveHealthGrowth`)을 다시 맞춘다.
- CoreSmoke 봇에 각인 선택(꼬리표 몰아주기 단순 규칙)과 궁극기 누르기를 넣고,
  목표: 빠른 봇 승률 55~70%, 사람 속도 봇 40~60%, 평균 6~9분, 1★ 일반검 벽 웨이브 5~12 유지.

## 7. 검증

- EditMode: 각인 뽑기(중복 없음·보스 보장), 효과별 1개 이상(합성 누적, 판매 2배, 화상 틱,
  둔화, 연쇄, 집중 우선 타깃, 궁극기 보관/발동), 전투력 계산.
- PlayMode: 휴식 진입 시 카드 화면이 뜨고 고르면 닫히며 적용됨, 궁극기 버튼은 100%에서만 눌림,
  적 탭 시 집중 대상 지정.
- CoreSmoke 밸런스 밴드(5절).
- 화면: VisualAuditCapture 1080×1920 + 실기기(1080×2340)에서 카드 화면·궁극기 버튼·HUD 겹침/잘림 확인.
- APK 빌드 0.13.0 (17), 실기기 설치·플레이.
