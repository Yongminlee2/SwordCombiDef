# Build and test

## Verified toolchain

- Unity `6000.3.18f1`
- Android minimum API 25
- Android target and compile API 36
- IL2CPP with ARM64
- No billing, advertising, or Google Play SDK dependency in the offline candidate

## Automated test command

```powershell
powershell -ExecutionPolicy Bypass -File .\Tools\run_tests.ps1
```

This runs Unity EditMode tests, Unity PlayMode runtime/UI tests, deterministic content
smoke checks, and 600 seeded balance simulations. The test wrapper deliberately omits
Unity's `-quit` argument because the test runner exits automatically after writing its
report.

## Windows build command

The Windows user and repository paths contain Korean characters. Unity's IL2CPP and
Android Prefab batch tools can misread those paths. The build wrapper mirrors only
`Assets`, `Packages`, and `ProjectSettings` into the real ASCII staging directory
`C:\SSBuildClean061`, builds there, and copies the artifact and log back to the
repository. Source files are not modified by staging.

```powershell
powershell -ExecutionPolicy Bypass -File .\Tools\build_android.ps1 `
  -Mode DevelopmentApk
```

The development APK is written to:

`Builds/Android/Swordstellation-development.apk`
